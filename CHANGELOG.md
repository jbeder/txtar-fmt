# Change Log

All notable changes to the "txtar" extension will be documented in this file.

## [0.0.1] - 2026-02-18

### Added
- Initial release
- Syntax highlighting for txtar files
- Comment highlighting for lines before/after file markers
- Filename highlighting in file marker lines
- Embedded language support for common file types:
  - Go (.go)
  - Python (.py)
  - JavaScript (.js)
  - TypeScript (.ts)
  - JSON (.json)
  - YAML (.yaml, .yml)
  - Markdown (.md, .markdown)
  - HTML (.html)
  - CSS (.css)
  - Shell (.sh, .bash)
  - Java (.java)
  - C (.c)
  - C++ (.cpp, .cc, .cxx, .h, .hpp)
  - Rust (.rs)
  - XML (.xml)
